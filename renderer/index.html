키워드 SEO 랜딩 · Cursor AI · Netlify 배포

「Netlify 로그인」으로 Chrome을 연 뒤 수동 로그인하세요. 크레딧은 상단 「↻」또는 사이트 배포 완료 시에만 빌링 페이지를 새로고침해 읽습니다.

https://site-ab123.netlify.app

형식: 키워드슬러그-영문2자+숫자3자리 (예: mobile-cash-xk847). 중복되지 않게 생성합니다.

지정한 횟수만큼 연속 생성합니다. 첫 사이트는 입력한 업체명·사이트명을 쓰고, 2개째부터 키워드·사이트명만 랜덤 재선택합니다(업체명 유지).

입력한 업체명이 사이트 로고·메타 타이틀(<title>)·홈/페이지 H1(Cursor AI 생성 시)에 핵심 키워드로 적용됩니다.

비워 두면 배포 전에 서치어드바이저 HTML 태그 인증코드를 먼저 받아 head에 넣은 뒤, Netlify에 1회만 배포합니다. (설정 탭 네이버 계정 필요)

고급 설정 (구글 · 키워드 수 · 저장 폴더 · 엔진)

홈 + 토픽 N페이지. 밝은 롱폼·이미지 카드·지금 전화/문자상담 구조로 생성합니다.

폴더 안 PNG/JPG/WEBP를 사이트마다 랜덤으로 골라 썸네일·히어로·OG에 넣습니다. 비어 있거나 없으면 미리보기처럼 자동 제작합니다.

Cursor API는 설정 탭의 「Cursor API Key」, Netlify 토큰은 「Netlify Tokens」에서 관리합니다.

정적 SEO 사이트 입력

모든 닷홈 계정에 이 비밀번호를 사용합니다.

https://(FTP아이디).dothome.co.kr

입력 시에만 「홈페이지 보기」 버튼이 생깁니다.

폴더에서 매번 랜덤으로 10장을 골라 사용합니다. AI로 이미지를 만들지 않습니다.

Search Console에서 받은 google….html 파일을 지정하면 사이트 루트에 동일 이름으로 포함됩니다. (나중에 구글 색인 가능)

비우면 {FTP아이디}.dothome.co.kr → 호스팅 IP 112.175.185.136 → 공용 FTP 순으로 시도합니다. 공용(211…)은 마지막입니다.

저장: Documents\Codex\호스팅\YYYY-MM-DD\DD일_FTP아이디_seo_site
생성 후 배포: FTP 업로드 → 네이버 서치어드바이저 등록 → HTML 인증 메타 주입 → 소유확인 → 인덱싱 (설정 탭 네이버 계정 필요)

위 버튼: 가입만. 아래 버튼: 가입 후 ZIP(있으면) 또는 AI SEO 생성 → FTP·네이버 등록. ZIP이 있으면 ZIP 개수만큼, 없으면 위 개수만큼 반복합니다.

① 네이버 메일 로그인 → ② 가입/풀파이프라인. 서치어드바이저는 설정 탭 네이버 계정을 사용합니다.
